Fantasy Stork League Backups

Backup privacy policy

Updated November 7, 2026

This policy covers the operator-only Fantasy Stork League Backups tool and its Google Drive connection. It describes the intended operation of the backup integration currently being configured.

Access and use

With the operator’s consent, the tool uses the Google Drive drive.file permission to create, upload, verify, list, download, and remove its backup files and dedicated folder. That permission also allows access to files explicitly opened with the app. The tool does not request general Drive access or access to Gmail, contacts, or photos. Drive file identifiers, sizes, checksums, timestamps, and available storage information are used to manage and verify recovery copies.

Backup contents and encryption

Backups can contain private league and account records, preferences, notification state, bug reports, bird tracking history, and application source/configuration. Packages are encrypted before being uploaded to Drive. The recovery key is kept separately from the uploaded packages. Filenames and file sizes remain visible to Google Drive. Hosted secret values are not included in source/configuration backups.

Processing and sharing

Cloudflare supplies the application data. The backup job is intended to run on GitHub Actions, where unencrypted data is temporarily processed for verification and encryption. Google Drive stores the encrypted copies in the operator’s account. OAuth credentials are stored as protected automation secrets; they are not published in the repository. Backup contents, credentials, and raw tracking evidence are not placed in public logs or workflow artifacts. These data are used only for backup, recovery, and operational verification—not advertising, sale, or training general-purpose AI models.

Retention and control

The intended retention is seven daily and four weekly recovery points, subject to available storage and verified backup size. Retention only removes backup files managed by this tool; unrelated personal Drive files are not removed. The operator can stop the automation, revoke its access in Google Account connections, and delete backup files from Drive. Revoking access does not itself delete previously saved files. Local recovery copies must be deleted separately.

Questions

Contact the operator using the support email displayed on the Google authorization screen, or use Settings → Contribute → Report a bug in Fantasy Stork League. Do not include credentials or recovery keys in a report.
