Fantasy Stork League Backups

A private recovery tool for the operator of Fantasy Stork League. It is being configured to save encrypted copies of the app databases and matching source configuration to the operator’s own Google Drive.

What it does

The tool checks database copies, encrypts backup packages before uploading them, and manages a limited number of recovery copies in a dedicated Drive folder. It is an administration tool, not a service that players need to connect to their Google accounts.

Google Drive access

The requested permission is limited to files created by this backup app or explicitly opened with it. It does not request general access to your Drive, Gmail, contacts, or photos. Only the operator authorizes access.
